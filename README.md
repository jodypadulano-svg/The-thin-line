# The Thin Line

Visual novel narrativa per adulti, sviluppata con Ren'Py 8.5. Tutti i personaggi sono maggiorenni.

Stato: **base giocabile dell'Episodio 1, senza grafica** (versione 0.1.0-dev).

## Documenti

- [Bibbia narrativa](docs/bibbia-narrativa.md) e [schede personaggio](docs/personaggi/)
- [Sistema di gioco](docs/sistema-di-gioco.md): statistiche, Diario, funzioni, scaletta dell'Episodio 1
- [Analisi dei giochi di riferimento](docs/analisi-riferimenti.md)

## Come giocarlo

1. Apri il launcher di Ren'Py (`C:\Users\Jody\RenPy\renpy-8.5.3-sdk\renpy.exe`).
2. In *Preferenze → Cartella dei progetti* scegli `C:\Users\Jody` (la cartella che contiene `the-thin-line`).
3. Seleziona **the-thin-line** e premi **Avvia progetto**.
